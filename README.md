# Acesso IA

Interface conceitual para representar uma inteligência artificial central conectada a diferentes tipos de dispositivos.

## Primeira tela

O núcleo **IA** conecta visualmente:
- Celular
- Computador
- Tablet
- Smart TV
- Smartwatch
- Games
- Automação
- Assistentes

A interface é responsiva, não depende de bibliotecas externas e pode ser aberta diretamente pelo `index.html`.

## Executar

Abra `index.html` no navegador.
